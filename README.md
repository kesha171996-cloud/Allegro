# Allegro Category Finder — независимая версия без API

Это простой сайт-справочник категорий Allegro для автозапчастей. Здесь **нет названия компании или фирменного оформления**, нет учётных записей, нет сторонних библиотек и **не требуются никакие API-ключи**.

## Как запустить

**Вариант 1: на своём компьютере.** Распакуйте ZIP и откройте `index.html` двойным нажатием. Работает офлайн, кроме кнопок, которые ведут на Allegro.

**Вариант 2: GitHub Pages.**

1. Создайте новый репозиторий на https://github.com/new (например `allegro-category-finder`).
2. Распакуйте ZIP и загрузите **все четыре файла** из папки: `index.html`, `style.css`, `app.js`, `examples.js`, а также этот `README.md`. Не нужно загружать сам ZIP.
3. В репозитории откройте `Settings → Pages → Build and deployment`.
4. Выберите `Deploy from a branch`, ветка `main`, папка `/(root)`, `Save`.
5. Сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/allegro-category-finder/`.

Ссылку можно дать любому человеку; не требуется ваш аккаунт Allegro или доступ к каким-либо вашим данным.

## Что делает сайт

- Вводит название детали + OEM и ищет совпадения в локальной базе.
- В комплекте **два демонстрационных товара**: экран теплозащитный (`254702`) и шланг охлаждения (`251124`).
- Для неизвестных товаров пишет «Не могу подтвердить точную категорию» и показывает кнопку «Найти деталь на Allegro».
- Можно вручную добавить категорию, отредактировать категорию, скопировать ID, посмотреть историю.
- Свои записи можно **скачать в JSON и импортировать в другом браузере**.

## Важные ограничения

- **Этот сайт без сервера, ИИ, API и полноценной локальной базы Allegro не способен автоматически распознавать любую новую запчасть, как ChatGPT.** Он не ищет категории Allegro в реальном времени и не может гарантировать стопроцентную точность.
- Даже подтверждение существования ID не доказывает, что категория подходит конкретной детали.
- Новые вручную добавленные категории сохраняются лишь в **локальном хранилище данного браузера**. Другой пользователь не увидит их автоматически: понадобится экспорт/импорт JSON или публикация новых базовых записей в коде репозитория.
- Если сайт загружен на GitHub Pages публично, сам сайт и включённые в код примеры доступны всем. **Не загружайте конфиденциальные данные в репозиторий.**
- Этот сайт не является официальным продуктом или сайтом Allegro.

## Если позже захочется автоматического поиска новых товаров

Потребуется база соответствий товаров и категорий, поддерживаемая вручную, **или** внешняя проверка через сервер/Allegro API/ИИ. Сам бесплатный GitHub Pages предоставляет только статическое размещение и не может выполнить защищённые запросы с секретными API-ключами.
