Настоящий ИИ — без API

Кнопка «Уточнить через ИИ» запускает многоязычную модель в браузере. При первом использовании браузер скачает модель — это может быть долго и расходовать трафик. Быстрый поиск работает и без модели.

Модель: paraphrase-multilingual-MiniLM-L12-v2, Transformers.js. ИИ не является официальным сервисом Allegro.
